학생회 건의 관리 창 사용설명서

문현고등학교 학생회 건의 관리 시스템의 주요 기능 및 상세 이용 방법 가이드입니다.

📌 개요
학생들이 제출한 건의를 효율적이고 체계적으로 관리하기 위해 제작된 웹 사이트입니다.
시스템 수정 요청이나 작동 문제가 발생할 경우 정보부 부장에게 문의해 주세요.

1. 로그인 이전

  1. 1. 홈 화면 및 로그인
    사이트 접속 시 메인 페이지가 연결됩니다. 본 시스템은 학생회 구글 계정으로만 접근이 가능하므로, 로그인 버튼을 눌러 승인된 계정으로 로그인해 주세요.
💡 학생회 구글 계정 안내
로그인 아이디와 비밀번호는 학생회 회장단 3명과 정보부 2명이 보유하고 있습니다.
계정 정보를 분실하였을 경우 정보부 부장에게 문의하여 주시기 바랍니다.
  • 2. 사용설명서
    현재 확인하고 계신 가이드 창입니다. 언제든지 로그인 화면이나 메인 페이지로 이동하려면 우측 상단의 '홈' 메뉴를 클릭하세요.
  • 3. 건의 제출
    상단 메뉴의 '건의 제출' 링크를 통해 일반 학생들이 건의를 제출하는 페이지로 이동할 수 있습니다. 건의 양식 및 수신 상태를 직접 확인해 보세요.

2. 로그인 이후 (건의 홈)

로그인 성공 후 처음으로 마주하는 메인 대시보드 화면입니다. 각 기능 카드를 클릭하면 해당하는 상세 페이지로 이동합니다.

2.1 메인 기능 카드

주요 통합 관리 탭에 대한 개요입니다.

기능 카드 상세 화면 (클릭 시 이동) 기능 설명
전체 건의 • 등록된 모든 건의글 목록 실시간 조회
• 키워드 검색 및 다중 조건 필터링 기능 지원
건의통계 • 분야별/유형별 건의 비중 시각화 (도넛/파이 차트)
• 월별 접수 및 처리 추이 그래프 분석
데이터 내보내기 • 조건별 건의 내역 선택 및 일괄 추출
• 엑셀(.xlsx) 및 CSV 파일 다운로드 지원

2.2 분류별 건의 & 관리 가이드

중앙의 4개 카드(건의 유형별 건의 날짜별 건의 현황별 즐겨찾기)는 조건에 따라 건의글을 간편하게 분류하여 보여줍니다.

⚙️ 건의 관리 및 상태 설정 팁
  • 메모 및 현황 업데이트: 각 건의 카드마다 직접 관리자 코멘트(메모)를 입력하고 처리 현황을 변경할 수 있습니다.
  • 실시간 공유: 작성한 코멘트와 현황은 시스템에 즉시 저장되며, 접속한 모든 학생회 관리자에게 동기화되어 공유됩니다.
  • 현황 분류 4단계:
    확인 안함 검토중 (회의 진행 또는 승인 대기) 처리완료 (건의 반영) 반려됨 (기각 또는 불가 사유)
⭐ 즐겨찾기 기능 이용법
각 건의 카드 우측 상단에 위치한 별 아이콘(☆)을 클릭하면 노란색(★)으로 활성화되며 즐겨찾기에 등록됩니다.
즐겨찾기 카드 탭을 활용해 주요 건의 사항만 모아서 빠르게 점검할 수 있습니다.
🔍 필터링 및 검색 기능 사용법
전체건의, 건의통계, 데이터 내보내기 화면 상단의 검색 패널을 통해 원하는 데이터를 정밀하게 탐색할 수 있습니다.
  • 키워드 검색: 건의 본문 또는 작성된 관리자 코멘트 내 특정 단어를 검색합니다.
  • 건의 시기: 시작일과 종료일을 지정하여 특정 기간에 접수된 건의를 필터링합니다.
  • 건의 유형: 제출 시 선택된 카테고리(시설, 급식, 학생복지, 학습환경, 행사 등)별로 분류합니다.
  • 건의 현황: 처리 상태별(확인 안함, 검토중, 처리완료, 반려됨)로 조회합니다.
  • 초기화 버튼: 모든 필터 조건을 해제하고 전체 목록을 출력합니다.
